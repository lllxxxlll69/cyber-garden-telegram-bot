Отчёты под рукой

Ваши проверки, PDF и доставка в Telegram.

Вход в аккаунт

При создании аккаунта: логин от 3 символов, пароль от 12.

Подключить Telegram

Создайте код и отправьте команду своему боту в личном чате. Код действует 5 минут и используется один раз.



Добавить отчёт
Загрузите JSON с массивом findings из Cyber Garden. PDF будет отправлен во все активные Telegram-сессии вашего аккаунта.


Автоматическая отправка из Cyber Garden
В настройках приложения укажите адрес webhook http://127.0.0.1:8787/api/reports и токен отдельной сессии. Добавьте блок HTTP webhook в сценарий. Токен показывается один раз; сессию можно завершить ниже.

Активные сессии
Завершение Telegram-сессии отключает новые отправки в этот чат.
